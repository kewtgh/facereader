上一篇文章，我们计算了德国普通家庭的生命周期综合汲取率（LCER）。

结果是：

> - **Munich（慕尼黑）：38.4%。**
> - **Cologne（科隆）：35.3%。**

德国的税收和社会保险负担很高。即使扣除了养老金、医疗等能够归属于家庭的福利，制度性净汲取仍然占到一个普通双职工家庭一生劳动价值的三分之一以上。

接下来，我想看看芬兰。

芬兰经常被当作北欧高税收、高福利国家的代表。它拥有覆盖面很广的公共教育、公共医疗和养老金体系，同时也要求劳动者及雇主承担相当高的税收和强制缴费。

根据OECD的统计，2021年芬兰一名单身、无子女、收入等于全国平均工资的劳动者，其劳动税楔（Tax Wedge）达到**42.7%**。[^tax-wedge] 这已经是相当高的水平。

按照通常对税负的理解，一个企业为了雇用劳动者付出100欧元，劳动者最后拿到手的金额与100欧元之间存在很大差距，似乎就可以认为国家从中拿走了很多。

但是，前面几个国家的计算已经说明，**缴纳了多少税费，与一个家庭最终有多少劳动价值被净汲取，是两回事。**

把家庭教育支出与1.5%的统一基线比较，保留低于基线的负差额后，本次得到的条件估算是：

> - **Helsinki（赫尔辛基）：28.85%。**
> - **Tampere（坦佩雷）：26.28%。**

教育项采用全国消费数据建立的家庭预算代理，并不是两座城市双职工一孩家庭的直接观测；这两个百分比也不代表已经精确测得了每个家庭的真实负担。[^education-data]

按这一估计，赫尔辛基的LCER低于此前计算的德国慕尼黑，也低于法国巴黎和加拿大多伦多；坦佩雷则与加拿大温尼伯比较接近。

那么，芬兰的税收不低，为什么最终算出来的LCER却没有德国那么高？

## 一、同样一个普通家庭，生活在赫尔辛基和坦佩雷

这次仍然沿用前面国家的标准家庭：夫妻两人，都是普通私人部门全职劳动者，养育一个孩子，从25岁开始工作，采用2021年作为基准年，实际贴现率2%，长期实际工资增长率0%。[^lcer][^pv]

芬兰在OECD 2021养老金模型中，平均收入劳动者的正常养老金年龄为68岁。因此，本文按照43年职业生涯计算。[^pension-age]

本文按年度末确认教育支出，并将收入、税费和既有福利现值按同一系数折算到可衔接的口径。分子与分母同步调整，不会单独放大汲取率；由于部分收付时点仍依赖模型假设，以下金额和比率属于这一假设下的条件估算。[^pv-timing]

城市仍然选择两个。

Helsinki是芬兰的主要经济中心，也是工资和住房价格较高的城市。Tampere则是重要的工业、科技和服务业城市，具有完整的就业市场，但普通住房价格明显低于首都。

芬兰统计局公布的2021年全国私人部门全职月薪中位数为**€3,520**。结合全国和地区的工资差异，模型估算赫尔辛基对应的普通私人部门月工资约为€3,886，坦佩雷约为€3,462。[^wages]

这里的城市工资是根据官方地区工资比例推算出的代表值，并不是统计局直接公布的这两座城市私人部门工资中位数。

按照夫妻两人收入相同的标准家庭设定：

| 项目 | Helsinki | Tampere |
| --- | ---: | ---: |
| 单人月工资 | €3,886 | €3,462 |
| 单人年工资 | €46,632 | €41,544 |
| 家庭年现金工资 | €93,264 | €83,088 |
| 雇主额外强制缴费率 | 19.7% | 19.7% |
| 家庭年度劳动价值 | €111,673 | €99,489 |
| **生命周期劳动价值现值** | **€3,200,733** | **€2,851,503** |

*年度工资和劳动价值保持2021年口径，现值采用上文的同步条件换算。正文分项金额通常取整，最终汇总使用计算表中的未舍入金额。*

芬兰雇主除了支付现金工资，还必须承担与养老金、医疗和其他社会保险有关的法定缴费。模型把这部分雇主强制劳动成本也放进分母，而不是只计算雇员收到的工资。

因此，一个赫尔辛基普通双职工家庭，从25岁工作到68岁，创造的劳动价值折算到25岁时，大约是**320.1万欧元**；坦佩雷约为**285.2万欧元**。

下面，我们仍然沿着这个家庭一生实际承担的缴费、税收、住房融资，以及能够获得的福利来计算。

## 二、芬兰养老金：24.4%的缴费，并不代表24.4%的汲取

芬兰最重要的强制社会保险之一，是与劳动收入挂钩的养老金制度。

2021年，芬兰私人部门雇员的法定收入关联养老金制度TyEL，平均总缴费率为工资的**24.4%**，其中相当大的一部分由雇主支付。[^tyel]

<figure class="fr-figure"><img src="https://kewtgh.github.io/PicSunflowers/img/2026/ai-finland-the-government-took-the-money-01.jpg" alt="ai-finland-the-government-took-the-money-01" /></figure>

这个比例并不低。

不过，养老金与普通税收不同。工作期间持续缴费，退休以后会形成领取养老金的权利。芬兰的收入关联养老金待遇与个人职业收入、累积年限等因素相关，因而不能简单地把一生缴纳的24.4%都算作被汲取的财富。

OECD 2021模型给出的芬兰平均收入劳动者完整职业生涯养老金毛替代率约为**56.6%**。由于本文统一从25岁开始计算，而OECD完整职业生涯的假设不同，芬兰模型将其调整到约**53%**。这里的替代率，是退休后的税前年养老金相对于退休前税前年工资的比例；53%是本文采用的模型参数，不是所有芬兰退休者实际领取比例的统计平均值。[^pension-age]

那么，退休后每年能够领取多少养老金，又能领取多少年？这两项都需要明确，才能计算退休福利。

先看领取年限。芬兰统计局2021年生命表中，已经活到68岁的男性，平均还有**16.19年**的剩余寿命；女性则为**19.38年**。换算成条件预期达到的年龄，分别约为**84.19岁**和**87.38岁**。这里必须使用“已经活到68岁之后”的条件剩余寿命，不能拿出生时的平均预期寿命直接减去68岁。[^life-expectancy]

| 寿命与领取期参数 | 男性 | 女性 |
| --- | ---: | ---: |
| 本文设定的退休年龄 | 68岁 | 68岁 |
| 2021年生命表：68岁条件剩余寿命 | 16.19年 | 19.38年 |
| 条件预期达到的年龄 | 84.19岁 | 87.38岁 |
| 本文采用的整年领取期近似 | 16年 | 19年 |

官方生命表保留小数，本文的养老金现金流则采用男性16年、女性19年的整年近似。这是一种定期领取模型，不是逐岁计算存活概率的精算结果，也不是预测每个人都会在84岁或87岁去世。生命表反映的是2021年的死亡率条件，本文没有另外预测未来几十年的寿命变化。[^pension-cashflow]

再看领取金额。长期实际工资增长按0%设定，两座城市的单人年工资分别为€46,632和€41,544。按53%的毛替代率计算：

\[
\text{单人税前年养老金}=\text{单人退休前年工资}\times53\%
\]

| 养老金领取金额，按2021年购买力计 | Helsinki | Tampere |
| --- | ---: | ---: |
| 单人退休前年工资 | €46,632 | €41,544 |
| 模型养老金毛替代率 | 53% | 53% |
| **男性每年领取的养老金** | **€24,714.96** | **€22,018.32** |
| **女性每年领取的养老金** | **€24,714.96** | **€22,018.32** |
| 每人月均领取金额 | €2,059.58 | €1,834.86 |
| 夫妻两人均在领取时的家庭年养老金 | €49,429.92 | €44,036.64 |

夫妻工资相同，是本文标准家庭的设定，因此男女各自的年养老金也相同，并不是说芬兰实际退休男性和女性的平均养老金相同。女性在模型中的领取期更长，所以累计领取额更高。按16年和19年分别计算，赫尔辛基男性累计领取约39.54万欧元，女性约46.96万欧元；坦佩雷分别约35.23万和41.83万欧元。这些金额尚未折现，也不是把未来通胀计入后的名义总额。

最后，把这些养老金逐年折算到25岁开始工作时。68岁退休对应\(t=43\)，第一笔完整年度养老金在退休后的第一年末确认，即\(t=44\)。男性共领取16笔，计至\(t=59\)；女性共领取19笔，计至\(t=62\)。退休期间的养老金购买力在这一近似模型中保持不变，夫妻各自的领取额分别计算，不把两人的年养老金一直合计到女性领取期结束。[^pension-cashflow]

以赫尔辛基为例：

\[
PV_{\text{养老金福利}}
=
24,714.96\times
\left(
\sum_{t=44}^{59}\frac{1}{1.02^t}
+
\sum_{t=44}^{62}\frac{1}{1.02^t}
\right)
\approx €308,582
\]

同样计算，坦佩雷约为€274,912。两座城市的养老金福利现值分别约30.9万和27.5万欧元；与下表按汇总口径列示的金额，只有不足1欧元的中间舍入差异。[^pension-cashflow]

养老金缴费与福利扣回放在一起，得到：

| 养老金项目 | Helsinki | Tampere |
| --- | ---: | ---: |
| 养老金缴费现值 | €652,234 | €581,070 |
| 退休养老金福利现值 | €308,581 | €274,913 |
| **养老金净汲取现值** | **€343,653** | **€306,157** |
| **占生命周期劳动价值** | **10.74%** | **10.74%** |

对于赫尔辛基家庭，一生缴纳的养老金现值约为65.2万欧元，预计退休后领取的养老金现值约为30.9万欧元。

两者相减，剩下约**34.4万欧元**，相当于生命周期劳动价值的**10.7%**。坦佩雷的结果也是约10.7%。

这说明芬兰养老金确实向普通家庭提供了相当可观的退休收入，但从这个标准家庭自身的生命周期现金流来看，缴费现值仍然高于预计领取的福利现值。

这笔差额并不意味着养老金制度把钱浪费掉了。养老保险同时承担长寿风险保障、代际支付和收入再分配功能。LCER在这里衡量的，是这个标准家庭能够识别的缴费与未来福利之间的差额，而不是评价整个养老金制度是否有价值。

还有一点很有意思：德国模型中的养老金净汲取约为8.0%，芬兰反而达到10.7%。

所以，芬兰最后的综合汲取率较低，并不能简单归结为它的养老金净汲取率更低。

## 三、医疗：为什么芬兰会出现负汲取？

芬兰医疗这一项，与德国呈现出明显不同的结果。

在德国，法定医疗保险主要通过与劳动收入挂钩的医保缴费筹资。雇员和雇主都缴费，因此工资越高，缴费通常也越多。

芬兰的公共医疗体系则更多依靠公共财政筹资。居民使用的公共医疗服务，并不只由工资条上的专门医保缴费支付，大量资金来自一般税收。

这会改变我们在家庭生命周期账本中看到的结构。

按照当前模型，夫妻及一个孩子整个生命周期中，可合理归属于该家庭的公共医疗服务价值，折现后约为**€274,589**。这个数字使用公共医疗支出及不同年龄医疗资源使用情况估算，并不是某个真实家庭的医疗费用记录。[^health]

两座城市使用相同的家庭年龄结构和医疗服务归属假设，因此医疗福利现值相同。

| 医疗项目 | Helsinki | Tampere |
| --- | ---: | ---: |
| 专门医保融资及缴费现值 | €95,429 | €85,017 |
| 公共医疗福利现值 | €274,589 | €274,589 |
| **医疗净汲取现值** | **−€179,160** | **−€189,573** |
| **占生命周期劳动价值** | **−5.60%** | **−6.65%** |

也就是说，按照当前可识别的专门医保融资与公共医疗福利归属，赫尔辛基家庭的医疗净汲取约为**−5.60%**，坦佩雷为**−6.65%**。

这里的负数，并不是说芬兰政府直接给一个普通家庭额外发放了约18万欧元现金，也不是说芬兰医疗服务完全不需要居民支付成本。它表示：**在这项分类中，模型归属于家庭的医疗服务现值，高于单独列出的医疗保险缴费现值。**

因为芬兰医疗很大一部分是由所得税等一般财政收入支付的，而这些税收已经计入后面的所得税项目，所以必须把税收和医疗福利合在一起看，不能只根据这个负数判断芬兰医疗比德国便宜多少。

在家庭的整个财政与社会保障账本中，这个负数抵消了一部分养老金、所得税和消费税形成的净汲取。

坦佩雷的负值比例更大，还有一个原因：家庭收入较低，生命周期劳动价值分母较小；但在相同家庭结构的假设下，公共医疗服务的价值并没有按照工资同比例减少。

这一点也解释了芬兰两个城市最终LCER的部分差距。

## 四、所得税和消费税：福利不会让税收自动消失

有了养老金和医疗的净额，接下来才能看芬兰的所得税与消费税。

芬兰个人所得税涉及国家所得税、地方所得税及相关扣除。个人最终承担的有效税负，取决于收入水平和具体适用规则，不能直接把最高边际税率乘以家庭工资。[^income-tax]

模型计算的个人所得税现值为：

- Helsinki：**€542,637**，约占生命周期劳动价值的**16.95%**。
- Tampere：**€440,565**，约占生命周期劳动价值的**15.45%**。

仅所得税这一项，对于芬兰普通双职工家庭来说就已经是一笔很大的长期支出。

而且，在缴纳所得税、取得税后收入以后，家庭还需要为商品和服务支付增值税（VAT），以及能源、酒类、烟草等商品所涉及的特别消费税。[^vat]

2021年芬兰标准VAT税率为24%，但实际家庭消费由不同税率商品及免税项目组成，因此模型使用家庭消费负担估计，而不是对全部工资直接乘以24%。

| 税费及社会保障项目 | Helsinki | Tampere |
| --- | ---: | ---: |
| 养老金净汲取 | €343,653 | €306,157 |
| 医疗净汲取 | −€179,160 | −€189,573 |
| 个人所得税 | €542,637 | €440,565 |
| 增值税负担 | €173,769 | €158,860 |
| 其他消费税 | €33,099 | €30,259 |
| **财政及社会保险净汲取** | **€913,998** | **€746,269** |
| **占生命周期劳动价值** | **28.56%** | **26.17%** |

现在，芬兰财政和社会保障的整个计算就比较清楚了。

对于赫尔辛基家庭，养老金净汲取约34.4万欧元，所得税约54.3万欧元，增值税与其他消费税合计约20.7万欧元；与此同时，医疗福利在专门医保缴费之外又抵消约17.9万欧元。

最后得到**28.56%**，坦佩雷则是**26.17%**。

芬兰的普通家庭确实承担了不低的税收和社会保险成本。只是如果把它们在未来获得的养老金和医疗福利全部忽略，就无法理解这些税费最终形成了多大的净负担。

其他失业、工伤等社会保险项目，当前缺乏足够稳定的普通家庭生命周期领取概率和待遇数据，因此没有把全部缴费直接当作汲取，而是暂按净额为零处理。这是模型的保守处理，并不意味着这些制度没有缴费或没有财政成本。

## 五、赫尔辛基房价不低，但住房制度成本为什么是零？

芬兰住房这一项，看起来可能比医疗更容易引起误解。

根据芬兰统计局的数据，2021年赫尔辛基二手公寓的代表性成交价格约为每平方米**€4,775**，坦佩雷约为**€2,752**。[^house]

这一轮芬兰模型采用75平方米的标准住宅，因此得到：

| 住房项目 | Helsinki | Tampere |
| --- | ---: | ---: |
| 75平方米住宅价格 | €358,125 | €206,400 |
| 房价 / 家庭年现金工资 | 3.84倍 | 2.48倍 |
| 已确认的住房制度性成本（中心估值） | 0.0% | 0.0% |

赫尔辛基的一套普通住宅约35.8万欧元，价格是坦佩雷的1.7倍左右。

为什么LCER中的住房制度成本反而是0？

我们在上海、纽约、伦敦和慕尼黑的计算中，已经反复遇到同一个问题：**房价高，不等于整套房价都属于制度性汲取。**

房屋有建筑价值，土地本身也有区位价值。一个城市的就业机会、人口集聚、收入水平和住房供给状况，都可能影响房价。只有能够识别并可靠估算的制度性溢价，才能作为住房汲取单独计入。

芬兰同样存在城市规划和土地供应限制，但当前模型没有得到足够可靠的估计，可以把赫尔辛基房价中的某个明确金额归因于规划限制，而不混入正常的土地稀缺和区位价值。因此，没有人为给赫尔辛基增加一个住房制度溢价。

另外，芬兰过去也有住房转让税。

但是，按照2021年的制度规定，符合条件的18至39岁首次购房者，如果购买至少50%产权并将住宅用于自住，可以免缴转让税。该首次购房豁免从2024年开始取消。[^transfer]

本文设定的家庭在25岁开始工作，在职业第10年，也就是大约35岁时首次购房，符合模型采用的2021年首次购房豁免条件。因此，在固定2021年制度口径的计算中，这一项不需要额外计入。

**住房制度成本为0.0%，表示这次没有识别到需要进入中心估值的净汲取，并不表示芬兰房地产没有税收，也不表示城市规划不会影响房价。**

和上海相比，两种住房制度的区别也很清楚。

上海模型能够识别出规模很大的土地及房地产财政链成本，因此购房成为居民部门向制度体系转移财富的重要渠道。

芬兰这次无法建立同样的土地财政链估计。高房价本身不足以支持把一笔庞大的制度性成本加进LCER。

## 六、房贷利率不到1%，购房没有制造第二轮巨额融资成本

住房价格之外，还有按揭贷款。

在上海模型中，较高的住房价格叠加长期贷款利息，形成了另一笔很大的生命周期成本。即使购房本金最终转化为家庭资产，支付给融资体系的利息也不会变成家庭的房屋产权。

芬兰在2021年的住房融资环境与此差别非常大。

<figure class="fr-figure"><img src="https://kewtgh.github.io/PicSunflowers/img/2026/ai-finland-the-government-took-the-money-02.jpg" alt="ai-finland-the-government-took-the-money-02" /></figure>

根据芬兰央行数据，2021年11月新发放住房贷款平均利率约为**0.76%**，其中自住房贷款约为**0.74%**。同期自住房贷款的平均期限约为**21年3个月**。[^mortgage]

沿用30%首付、70%贷款的家庭购房设定：

| 房贷项目 | Helsinki | Tampere |
| --- | ---: | ---: |
| 住宅价格 | €358,125 | €206,400 |
| 贷款本金 | €250,688 | €144,480 |
| 房贷利息现值 | €14,304 | €8,244 |
| **占生命周期劳动价值** | **0.45%** | **0.29%** |

赫尔辛基家庭需要借款约25.1万欧元，但按2021年的低利率和芬兰本地贷款期限模型，整个偿还期的利息折算到25岁时，仅约1.43万欧元。

占家庭一生劳动价值的**0.45%**。坦佩雷更低，只有**0.29%**。

这并不是说2021年以后芬兰的房贷利率会一直维持在这个水平。芬兰住房贷款有相当一部分与市场利率联系紧密，利率上涨会增加未来借款人的负担。这里使用的是2021年静态基准条件，以便和前面国家保持同一基准年比较。

但至少在这一基准下，芬兰住房融资并没有把普通家庭的住宅购买进一步放大成巨额利息支出。

## 七、教育支出低于基线，应该怎样计入？

芬兰的教育经常被当作福利国家的代表。不过，这里要计算的，并不是政府为学校花了多少钱，而是普通家庭自己承担的教育支出，相对于统一基线究竟多了还是少了。

本系列采用家庭教育支出占家庭消费的**1.5%**作为比较基线。高于这个比例，差额为正，增加LCER；低于这个比例，差额为负，降低LCER。低于基线的部分不再截断为零。[^education]

计算公式是：

> **年度超额教育竞争支出 =（家庭教育支出占家庭消费的比例 − 1.5%）× 家庭年度消费。**

芬兰统计局《Finland in Figures 2023》列出的2021年全国数据中，教育占家庭消费支出的比例为**0.4%**。这里的分母是家庭消费，不是GDP；但它来自全国国民账户，不能直接当作赫尔辛基或坦佩雷双职工一孩家庭的实测比例。本文将它用作教育消费结构的代理参数。[^education-data]

按照这个参数：

**0.4% − 1.5% = −1.1个百分点。**

这个负差额可以进入模型，但还不能直接从LCER中减去1.1个百分点。因为教育支出占比的分母是家庭消费，而LCER的分母是家庭整个生命周期的劳动价值，中间还需要换算家庭预算和支出发生的年份。

### 家庭每年消费多少钱？

本次采用芬兰统计局2022年家庭消费调查中双亲子女家庭的初步发布值：每个等价消费单位年消费约**€28,700**。这里的“等价消费单位”不是家庭人数，也不是每户家庭；它是考虑家庭成员年龄和共同生活规模后，用来比较消费水平的统计尺度。[^consumption-budget][^equivalence]

用2021年和2022年的总消费者价格指数105.8、113.4进行价格回推，每个等价消费单位的年消费约为：

**€28,700 × 105.8 ÷ 113.4 = €26,776.54。**

按照第一名成年人权重1、第二名成年人权重0.5、0—13岁儿童权重0.3、14岁及以上成员权重0.5的尺度，两名成年人加一个孩子，可以推算出两档家庭预算：

| 孩子年龄 | 家庭等价消费单位 | 家庭年度消费 | 按0.4%估计的教育支出 | 1.5%基线支出 | 年度教育差额 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 6—13岁 | 1.8 | €48,197.78 | €192.79 | €722.97 | −€530.18 |
| 14—18岁 | 2.0 | €53,553.09 | €214.21 | €803.30 | −€589.08 |

这两档金额都是2021年价格下的预算代理，不是两座城市的一孩家庭调查结果。价格回推只调整价格水平，不能还原2021年的全部消费行为；本次也没有按两城工资比例人为放大家庭消费差异。

### 一个孩子的教育差额，折现后是多少？

假设父母30岁生育，孩子6岁开始进入本文计算的教育阶段，计至18岁，共13年。每年的教育差额在年末确认，仍然按照2%的实际贴现率折算到父母25岁时。这个设定不再额外假定孩子读大学，也不会把教育差额延长到父母43年的全部职业生涯。[^education-timing]

孩子6—13岁的8个教育年份，每年差额约为−€530.18；14—18岁的5个年份，每年差额约为−€589.08。折现后合计为：

**教育差额现值：−€5,029.55。**

赫尔辛基和坦佩雷采用相同的全国消费代理，因此教育差额金额相同。再分别除以两座城市家庭的生命周期劳动价值：

| 教育项 | Helsinki | Tampere |
| --- | ---: | ---: |
| 超额教育竞争支出现值 | −€5,029.55 | −€5,029.55 |
| **对LCER的影响** | **−0.1571个百分点** | **−0.1764个百分点** |

也就是，赫尔辛基扣减约**0.16个百分点**，坦佩雷扣减约**0.18个百分点**。

这里的负数表示，相对于1.5%的教育消费基线，这个家庭在代理模型中承担的教育支出更少。它不是政府发给家庭的现金，也没有把学校的生均经费作为另一笔教育福利再扣回来。

芬兰教育项的负向调整没有大到改变整个LCER的主要结构。原因也很直接：差额只作用于一个孩子的13个教育年份，而最终分母是夫妻两人的整个职业生涯劳动价值。

城市土地规划造成的额外住房溢价、公共事业中的潜在制度成本，以及其他缺乏可靠量化依据的项目，仍然没有进入本次估计。公共医疗福利的家庭归属、部分现金流的时间安排，以及教育项采用的全国代理数据，都是理解最终数字时需要保留的估算边界。[^model-limits]

## 八、最后，芬兰的LCER是多少？

把已经计入的项目放到一起，芬兰的结果如下：

| 项目 | Helsinki | Tampere |
| --- | ---: | ---: |
| 财政及社会保险净汲取 | 28.56% | 26.17% |
| 住房制度性成本（已计入部分） | 0.00% | 0.00% |
| 房贷利息 | 0.45% | 0.29% |
| 超额教育竞争支出（带符号代理估算） | −0.16% | −0.18% |
| 尚未可靠量化的住房、垄断及其他成本 | Not Included | Not Included |
| **Core LCER（条件估算）** | **28.85%** | **26.28%** |
| **Total / Extended LCER（条件估算）** | **28.85%** | **26.28%** |

*分项均为占生命周期劳动价值的比例，保留两位小数；教育行的−0.16%和−0.18%，表示分别降低LCER约0.16和0.18个百分点。总额使用计算表中的未舍入结果，不通过已舍入的分项倒推。未量化项目仍未计入，Core与Extended相同不代表已经覆盖全部制度成本。*

相应的金额为：

| 项目 | Helsinki | Tampere |
| --- | ---: | ---: |
| 家庭生命周期劳动价值现值 | €3,200,733.33 | €2,851,502.94 |

| **计入教育项后的制度性净汲取现值** | **€923,272.41** | **€749,483.20** |

也就是说，按本文的家庭设定与条件换算口径，赫尔辛基家庭的生命周期净汲取现值约为**92.33万欧元**，坦佩雷约为**74.95万欧元**。[^calculation]

赫尔辛基和坦佩雷相差约2.56个百分点，主要差距仍来自所得税和医疗福利相对劳动价值的比例。

赫尔辛基家庭工资更高，个人所得税负担也更高。模型中两座城市获得的公共医疗福利现值相同，放到坦佩雷较低的劳动价值分母上，抵扣比例就更大。教育差额采用相同的全国预算代理，也会给坦佩雷带来稍大的比例抵扣。

房价也有影响，但在2021年的低利率假设下，按揭利息只给两座城市带来约0.16个百分点的LCER差距。芬兰的主要制度性净汲取，仍然集中在财政与社会保障体系。

芬兰2021年全国平均工资、单身无子女劳动者的传统劳动税楔为42.7%；本文赫尔辛基双职工一孩家庭的LCER条件估算则为28.85%。这两个数字对应的家庭和时间范围不同，不能把差额直接理解为福利返还率，但它们说明了为什么仅凭工资条上的扣款，无法回答本系列的问题。

此前计算的德国慕尼黑LCER达到38.4%。加拿大多伦多则为34.1%，其中有一部分相当大的成本来自住房制度和融资。芬兰的构成又有所不同：养老金仍有较高的净汲取，公共医疗抵消了一部分税费，住房融资成本很低，低于基线的教育支出则带来一笔较小的负向调整。

**一个国家税收很高，不必然意味着它在LCER中一定排在最前面。** 但高税收仍然有代价，芬兰普通家庭需要把相当大的一部分劳动价值交给公共体系。

如果只看每年工资条上的扣款，芬兰确实是一个税费负担很高的国家；但把一个家庭一生缴纳和获得的东西，以及为住房和教育额外承担的支出放在一起，看到的结果就不同了。芬兰没有改变高税收这个事实，它只是让我们看到：缴给公共体系的钱最后去了哪里，家庭还需要在公共体系之外承担多少支出，同样重要。

[^lcer]: **LCER（Lifecycle Comprehensive Extraction Rate，生命周期综合汲取率）**：本系列定义为“制度性净汲取现值 ÷ 家庭生命周期劳动价值现值”。制度性净汲取包括可识别的强制支付及制度性间接成本，扣除可以合理归属于标准家庭的养老金、医疗等福利。本文教育项另按家庭教育消费相对于1.5%基线的正负差额进行调整，不扣回政府教育经费。LCER不是家庭总支出率、税率或家庭剩余收入的反面。
[^pv]: **PV（Present Value，现值）与实际贴现率**：将不同时点的现金流按照统一贴现率折算到家庭25岁开始工作时的价值。本文使用2%实际贴现率、长期实际工资增长率0%，作为跨国比较的统一模型假设。

[^tyel]: **TyEL（Employees Pensions Act）**：芬兰私人部门雇员的法定收入关联养老金制度。2021年平均总缴费率为工资的24.4%，包括雇主与雇员部分。该缴费率的分母是现金工资，不是本文加入雇主法定劳动成本后的LCER劳动价值。来源：[Finnish Centre for Pensions, Year-by-year Changes](https://www.etk.fi/en/finnish-pension-system/financing-and-investments/financing-principles/year-by-year-changes/)。
[^pension-age]: **芬兰养老金模型的退休年龄与替代率**：OECD《Pensions at a Glance 2021》对芬兰平均收入劳动者的模型正常养老金年龄为68岁，完整职业生涯强制养老金毛替代率为56.6%。本文依据25岁开始工作的统一设定作职业年限近似调整，计算采用53%，不将其当作实测平均替代率。毛替代率以税前年养老金除以退休前税前年工资；本文所列领取额也都是税前金额，未在本段另行估算退休所得税。这不代表2021年所有实际芬兰居民都在68岁退休。来源：[OECD, *Pensions at a Glance 2021*, Gross Pension Replacement Rates](https://www.oecd.org/en/publications/pensions-at-a-glance-2021_ca401ebd-en/full-report/component-16.html)。
[^life-expectancy]: **68岁条件剩余寿命（Remaining Life Expectancy at Age 68）**：在已经活到68岁的条件下，按给定时期的死亡率计算还能生存多少年。芬兰统计局2021年生命表68岁行，男性为16.19年、女性为19.38年；分别加上68岁，得到84.19岁和87.38岁的条件预期达到年龄。这不是出生时预期寿命，也不是未来退休世代的寿命预测。数据采用全国口径，未设赫尔辛基与坦佩雷差异。来源：[Statistics Finland, StatFin 12ap — Life table by age and sex](https://pxdata.stat.fi/PXWeb/pxweb/en/StatFin/StatFin__kuol/12ap.px)；[Human Life-Table Database收录的芬兰统计局2021年生命表，68岁行](https://www.lifetable.de/File/GetDocument/data/FIN/FIN000020212021CU1.pdf)。
[^pension-cashflow]: **养老金领取期、年度领取额与现值近似**：本文补充的可复算现金流采用男性16年、女性19年的整年领取期，分别对应2021年生命表16.19年、19.38年的近似；两者不能写成完全相同的统计数值。单人年度养老金为工资×53%，按不变的2021年购买力计算。退休时点为t=43，年度末养老金从t=44开始，男性计至t=59、女性至t=62。按这一设定直接计算，Helsinki男性PV €143,211.88、女性€165,369.72，未舍入合计€308,581.59；Tampere男性PV €127,586.08、女性€147,326.29，未舍入合计€274,912.37。汇总表沿用先取整再同步换算的€308,581.37和€274,912.75；与直接复算相差分别约€0.22和€0.37，不影响本文两位小数的LCER。该整年模型可复现汇总金额，但不等于已取得原始逐年记录，也不是完整的存活概率加权精算。按完整小数领取期计算会得到略高的养老金福利现值；本篇仅补充既有整年近似的依据与算式，不据此改动已公布的条件结果。未另行估算配偶遗属养老金、领取期间实际指数调整或退休前死亡风险。

[^health]: **公共医疗福利归属（Public Healthcare Benefit Attribution）**：按照家庭成员年龄结构及芬兰公共医疗服务支出，估算标准家庭终身可以获得的公共医疗服务现值。€274,589是模型化归属值，不是某一家庭的真实就医记录，也不是现金转移支付。芬兰医疗大量由一般财政收入支持，因此必须与所得税等税收项目一起解释。
[^income-tax]: **有效所得税（Effective Income Tax）**：实际应缴个人所得税相对于应税收入的综合结果，受到不同税阶、扣除和家庭状况影响，不等于最高边际税率。本文采用所提供模型中的家庭生命周期所得税估计。
[^vat]: **VAT（Value Added Tax，增值税）及消费税归宿（Tax Incidence）**：VAT是对商品和服务消费征收的间接税。消费者最终负担取决于消费结构、税率、价格传导和免税规则，不能直接用法定标准税率乘以全部工资。本文把VAT和其他特别消费税分列，避免重复计算。
[^house]: **芬兰住房价格口径**：2021年两城旧住房代表性价格采用Helsinki约€4,775/平方米、Tampere约€2,752/平方米；芬兰本轮样本为75平方米公寓，因此与此前采用80平方米住房的部分国家并非完全同面积比较。住房价格不是住房制度性汲取额。来源：[Statistics Finland, Prices of Dwellings in Housing Companies, 2021](https://stat.fi/til/ashi/2021/12/ashi_2021_12_2022-01-28_tie_001_en.html)。
[^transfer]: **首次购房转让税豁免（First-time Homebuyer Transfer Tax Exemption）**：芬兰2021年的规则允许符合条件的18至39岁首次自住购房者免缴转让税；豁免适用于2024年1月1日前签署的交易。本文采用2021年制度静态基准，模拟职业第10年购房，并不声称这一豁免在假想的未来购房年份仍然有效。来源：[Finnish Tax Administration, Buying Your First Home](https://www.vero.fi/en/individuals/property/transfer-tax/buying_your_first_hom/)。
[^mortgage]: **芬兰2021年按揭利率与期限**：芬兰央行统计显示，2021年11月新住房贷款平均利率为0.76%，新自住房贷款平均利率为0.74%，平均自住房按揭期限21年3个月。本文依照提供的芬兰模型进行2021年利率静态模拟；利率后续变化会影响实际生命周期融资成本。来源：[Bank of Finland, *Housing Loan Market Remained Brisk in November 2021*](https://www.suomenpankki.fi/en/statistics/statistical-news/mfi-balance-sheet/2022/housing-loan-market-remained-brisk-in-november-2021/)。
[^education]: **超额教育竞争支出（带符号基线差额）**：本篇按“（本地家庭教育支出占家庭消费的比例−1.5%）×家庭消费”计算每年差额，允许负值，不使用`max(..., 0)`归零。1.5%沿用项目指定的日本比较基线；其作用是统一比较基准，不是本文重新验证的芬兰统计事实。负值表示相对基线的支出较少，不等于现金福利或政府教育经费返还。年度差额需按实际纳入的教育年份折现，再除以生命周期劳动价值，不能将消费占比差额直接从LCER中扣除。
[^model-limits]: **条件估算、代理参数与Not Included**：本文沿用既有工资、养老金、医疗、税费和按揭模块，本次更新不代表对这些模块重新完成独立认证。教育项使用全国教育消费份额、2022年双亲家庭消费初步值和等价尺度推算，而非两城2021年双职工一孩家庭的直接调查。统计分类中的教育消费也不必包括所有与儿童学习有关的支出，必须与基线范围一致。百分比的小数位只是运算结果，不代表同等统计精度。“Not Included”表示尚未可靠估算、未计入，不是已证明成本为零。

[^education-data]: **芬兰2021年教育消费占比**：《Finland in Figures 2023》印刷页23的“Households’ consumption expenditure”表列出2021年教育占家庭消费0.4%，该年一栏带初步数据标记，来源为全国年度国民账户。该比例以家庭消费为分母，公布精度为0.1个百分点，不是教育私人资金占GDP的比例，也不是双职工一孩家庭专属数据。本文保留该历史公布值作为代理输入，不声称它是最新修订终值。来源：[Statistics Finland, *Finland in Figures 2023*](https://toolbox.finland.fi/wp-content/uploads/sites/2/2023/06/finland-in-figures-2023.pdf)。
[^consumption-budget]: **家庭消费预算与价格回推**：芬兰统计局2023年12月28日发布的2022年家庭消费调查初步结果中，双亲子女家庭每等价消费单位年消费约€28,700。本次用2021年总CPI 105.8与2022年113.4（2015=100）回推为2021年价格，得到€26,776.54。价格回推不校正实际消费数量与结构变化，也不能把2022年样本变成2021年城市一孩家庭实测。来源：[Statistics Finland, Household Consumption Expenditure 2022, preliminary release](https://stat.fi/en/publication/cl8mrlcn2z9uh0dut08bwq5qf)；CPI见[《Finland in Figures 2023》印刷页21](https://toolbox.finland.fi/wp-content/uploads/sites/2/2023/06/finland-in-figures-2023.pdf)。
[^equivalence]: **等价消费单位（Equivalised Consumption Unit）**：按修正等价尺度，第一名成年人权重为1，其他14岁及以上成员为0.5，0—13岁儿童为0.3。两名成年人和一个孩子在儿童14岁前后分别对应1.8和2.0个等价单位。该尺度用于家庭预算标准化，不等于每个家庭一定按这个比例消费。来源：[Statistics Finland, Household Consumption Expenditure, table 14ph](https://pxdata.stat.fi/PxWeb/pxweb/fi/StatFin/StatFin__ktutk/14ph.px/)。
[^education-timing]: **教育期与付款时点**：父母25岁设为t=0，30岁生育为t=5。孩子6—18岁共13个年度，支出均在年末确认：6—13岁对应t=12至19，14—18岁对应t=20至24。用未舍入年度差额计算，PV = −530.1755556×Σ(t=12…19)(1.02)^(−t) −589.0839506×Σ(t=20…24)(1.02)^(−t) = −€5,029.549382。只计算这13年，不将差额重复计入父母全部43年职业期，也不另加未设定的大学教育年份。
[^calculation]: **本篇数值来源与汇总**：教育更新依据《2026-10-12-Finland-Signed-Education-Proxy-Calculation.xlsx》，其他分项沿用《芬兰.md》，并按同一条件系数同步换算。赫尔辛基LCER = [(946868÷1.02)−5029.549382]÷(3264748÷1.02) = 28.845652%；坦佩雷LCER = [(769603÷1.02)−5029.549382]÷(2908533÷1.02) = 26.283795%。正文多数分项金额取整，总表及教育预算保留至分；坦佩雷原底稿分项加总与财政社保汇总有约€1尾差，本文按最新计算表沿用汇总值计算。没有加入公共教育福利抵扣。
