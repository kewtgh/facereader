上一篇文章，我们计算了法国的生命周期综合汲取率（LCER）[^lcer]。

最后的结果是：

> - **Paris：34.0%。**
> - **Lyon：27.8%。**

法国是世界上税负最高的发达国家之一。大量的税收和社会保险缴费，在劳动者拿到工资之前就已经被收走了。

那么德国呢？

如果说法国是一个高税收、高福利的国家，德国显然也不会相差太远。

德国拥有相当完善的社会保障制度。养老金、医疗保险、失业保险、护理保险，以及针对儿童和家庭的各种福利，覆盖了居民生活中相当多的风险。

OECD在2021年的统计中，德国单身、无子女、收入等于全国平均工资的劳动者，传统劳动税楔[^tax-wedge]达到**48.1%**，甚至略高于法国同类劳动者的47.0%。

但这个数字并不是我们要计算的LCER。

因为一个德国人工作时缴纳的养老金，退休以后确实会有一部分返回来；医疗保险也会在生病时支付医疗费用。如果只计算缴费，不计算福利，显然会高估这个家庭真正承担的净成本。

所以，这次仍然采用和前面五个国家相同的计算方式。

最终得到的结果是：

> - **Munich（慕尼黑）：38.4%。**
> - **Cologne（科隆）：35.3%。**

这两个数字都高于法国的Paris和Lyon。

而且，德国和法国还有一个共同点：真正占据LCER绝大部分的，仍然是税收和社会保险。

但德国又有一点很特别。

慕尼黑的住房价格非常高。一套80平方米的普通产权公寓，在2021年的模型价格就已经达到**72.8万欧元**。

然而，最后能够计入LCER的住房制度成本只有0.5%，加上房贷利息也不过2.4%。

所以德国这篇文章，我觉得最值得解释的其实有两个问题：

**为什么德国拥有相当完善的福利制度，扣除福利以后，普通家庭的净制度成本仍然这么高？**

以及，为什么慕尼黑这么昂贵的住房，最后对LCER的贡献却如此有限？

## 一、还是同一个家庭，换成慕尼黑和科隆

前面五篇已经解释过完整的LCER框架，这里不再从头介绍。

仍然是一个标准家庭：夫妻两人，25岁开始工作，养育一个孩子；采用2%的实际贴现率[^discount-rate]，长期实际工资增长按0%计算；工作第10年购房，首付30%，贷款70%。

养老金正常领取年龄按照67岁计算，职业生涯42年。

住房仍然使用80平方米的标准家庭住宅。购房本金不算汲取，因为这部分支出最终转化成了家庭资产。养老金和医疗福利也必须扣回来。

这一次，Leading City[^city-type]选择慕尼黑，Representative City选择科隆。

慕尼黑的工资和生产率在德国主要城市中处于较高水平，同时也是德国最昂贵的住房市场之一。科隆同样是一座大型经济中心，但住房成本明显低于慕尼黑，更适合作为德国普通大型城市的参照。

根据德国联邦就业局2021年社会保险就业工资数据[^median-wage]，两个城市全职劳动者的月工资中位数分别约为：

- Munich：**€4,681**
- Cologne：**€3,988**

换算成年工资，一个慕尼黑普通劳动者大约获得€56,172，科隆则是€47,856。

但和法国一样，雇主实际付出的劳动成本并不只有工资。

德国企业还必须在员工现金工资以外承担雇主法定社会保险缴费。本模型使用约21.1%的雇主强制缴费率。

因此，两座城市的标准家庭计算结果是：

| 项目                   | Munich         | Cologne        |
| ---------------------- | -------------- | -------------- |
| 单人年工资             | €56,172        | €47,856        |
| 家庭年现金工资         | €112,344       | €95,712        |
| 雇主法定缴费率         | 21.1%          | 21.1%          |
| 家庭年度劳动价值       | €135,998       | €115,864       |
| **生命周期劳动价值PV[^pv]** | **€3,916,674** | **€3,336,829** |

也就是说，一个慕尼黑双职工家庭，从25岁开始工作直到67岁退休，一生创造的劳动价值现值大约是：

**391.7万欧元。**

科隆则约为：

**333.7万欧元。**

后面的所有汲取率，都以这两个数字为分母。

这里再次强调一点：分母不是家庭最终拿到手的工资，而是雇主为了获得这两个人的劳动，依法需要支付的全部劳动成本。

否则，发生在工资进入员工账户以前的制度性成本，就会被遗漏。

## 二、德国的社会保险：钱首先在工资发放以前被分配

德国社会保障体系中一个非常明显的特点，是大量支出直接和劳动收入绑定。

2021年，德国法定养老保险（Gesetzliche Rentenversicherung）[^grv]总缴费率为18.6%，通常由雇主和雇员各承担9.3%。

法定医疗保险（Gesetzliche Krankenversicherung，GKV）[^gkv]的一般缴费率为14.6%，加上2021年平均1.3%的附加缴费，合计约15.9%。

另外还有失业保险、长期护理保险以及工伤保险等制度。

从一名普通劳动者的工资来看，社保缴费确实相当高。

但是这些钱并不完全等同于税。

养老保险建立了未来养老金领取权。医疗保险对应实际医疗服务。失业保险和护理保险也为居民提供风险保障。

因此，德国的养老金与医疗仍然采用和前面国家相同的计算原则：

**生命周期强制缴费，减去可归属于这个家庭的生命周期福利。**

只有差额才进入净汲取。

这个差额代表的是标准家庭在模型中没有以相应个人福利形式收回的部分，并不意味着所有没有回到家庭账户的钱都被浪费了。

社会保险本来就存在代际转移、收入再分配和风险共担。

但这些钱究竟回到了谁的身上，和一个普通家庭最终承担了多少净成本，是两个不同的问题。

## 三、养老金：交出去的很多，最后能回来多少？

德国养老金制度与英国有明显区别。

英国的State Pension比较接近统一标准给付，虽然领取资格与缴费记录有关，但养老金金额并不会随着退休前工资同比例上升。

德国的法定养老金则采用养老金积分体系（Entgeltpunkte）[^entgeltpunkte]。

一个人在职业生涯中获得的工资、缴费年限及其相对于德国平均工资的位置，会影响退休以后的养老金。

收入高一些，缴费通常更多，获得的养老金积分也更多。

这意味着慕尼黑家庭不仅在工作期间缴纳更多养老金，退休以后也有机会得到更高的养老金。

那么最后的差额有多少？

OECD的长期养老金模型中，德国平均工资劳动者的强制养老金毛替代率[^replacement-rate]约为41.5%。

但OECD的完整职业生涯从22岁开始，而本系列统一从25岁开始，因此德国模型按42年相对于45年的缴费年限进行近似调整，得到38.7%。

退休后的养老金领取期也没有简单使用出生时预期寿命，而是按照已经活到67岁之后的条件剩余寿命[^conditional-life]估算。

最终得到：

| 养老金项目             | Munich       | Cologne      |
| ---------------------- | ------------ | ------------ |
| 强制养老金缴费PV       | €601,794     | €512,701     |
| 养老金福利PV           | €288,126     | €245,470     |
| **养老金净汲取PV**     | **€313,668** | **€267,231** |
| **占生命周期劳动价值** | **8.0%**     | **8.0%**     |

慕尼黑家庭一生缴纳的养老金现值约60.2万欧元，预计获得的养老金福利现值约28.8万欧元。

最终进入LCER的净额是：

**31.4万欧元，相当于8.0%。**

科隆也是8.0%。

为什么两座城市相同？

因为在当前模型中，养老金缴费和未来养老金待遇都与职业收入密切关联。收入更高会提高缴费，也会提高退休福利。

因此，两座城市虽然绝对金额差别明显，但最终占劳动价值的净汲取比例非常接近。

这里也能看到德国和英国之间的区别。

英国的Manchester虽然工资明显低于London，但退休以后能够领取的完整State Pension并不会相应地大幅下降。

德国的收入差距则会更多地延续到养老金中。

不过，**8.0%的净养老金成本，已经相当于一个家庭整个生命周期劳动价值的十二分之一左右。**

这还是扣除了退休福利以后的数字。

## 四、医疗：收入越高，交得越多，但看病不一定更多

德国的法定医疗保险又体现出另一种结构。

GKV缴费主要与收入相关，在缴费上限以内，工资越高，缴费越多。

但一个人能够获得多少医疗服务，并不由工资直接决定。

同样的疾病、同样的治疗需求，并不会因为一个人的工资比另一个人高20%，医疗服务的价值就自动提高20%。

德国2021年法定医保的人均实际福利支出约为€3,594。

当然，人一生中使用医疗资源的情况并不平均。年轻时医疗支出通常较低，进入老年以后明显增加。

所以德国模型仍然按照年龄调整医疗福利，计算夫妻从年轻到退休以后的医疗使用，并纳入一个孩子的医疗福利。

这部分是模型估计，不是直接观察到某个真实家庭一生的医保理赔记录。

最终得到：

| 医疗保险项目           | Munich       | Cologne      |
| ---------------------- | ------------ | ------------ |
| 医保缴费PV             | €537,343     | €457,792     |
| 医疗福利PV             | €275,741     | €275,741     |
| **医疗净汲取PV**       | **€261,602** | **€182,051** |
| **占生命周期劳动价值** | **6.7%**     | **5.5%**     |

慕尼黑和科隆家庭的医疗福利现值相同，是因为我们使用了相同的家庭年龄结构和医疗服务使用假设。

但慕尼黑家庭缴纳的医保更多。

所以最后得到：

> - **Munich：6.7%。**
> - **Cologne：5.5%。**

这里和养老金不一样。

养老金的缴费和待遇大致一起上升，而医保缴费的上升，并不会自动带来等比例的个人医疗福利增长。

因此，在相同年龄和健康状况假设下，收入越高的家庭，医保净缴费缺口通常越大。

这也体现了德国社会医疗保险的再分配性质。

大家熟悉的高福利制度，并不是把每个人交进去的钱原样存起来，等到未来再还给他。

它把不同收入、不同健康状况以及不同年龄人群连接在一起，让一部分人的缴费支持另一部分人的医疗需求。

这可以提供重要的社会保障价值，但从一个具体家庭的生命周期账本看，净支出仍然存在。

仅仅养老金和医保两项，

- 慕尼黑家庭的净汲取就已经达到：

  **8.0% + 6.7% = 14.7%。**

- 科隆则是：

  **8.0% + 5.5% = 13.5%。**

而所得税和消费税，还没有开始计算。

## 五、德国所得税并不低，消费以后还有一轮税

德国个人所得税（Einkommensteuer）[^einkommensteuer]采用累进税率。

收入越高，适用的边际税率越高。

但这并不意味着一个收入较高的家庭，全部收入都按照最高边际税率缴税。

德国还有劳动费用扣除、社会保险扣除、夫妻联合报税规则，以及儿童福利和税收减免等制度。

2021年，第一个孩子的Kindergeld[^kindergeld]为每月€219。

本模型假定孩子在夫妻职业生涯第5年出生，并按18年计算相应儿童税收及现金福利。

所以这里计算的不是一个抽象的最高税率，而是按照家庭收入、扣除和育儿阶段模拟出的生命周期所得税净负担。

结果：

| 项目           | Munich    | Cologne   |
| -------------- | --------- | --------- |
| 个人所得税PV   | €554,163  | €416,606  |
| **占劳动价值** | **14.2%** | **12.5%** |

仅所得税这一项，慕尼黑家庭就需要拿出相当于一生劳动价值14.2%的钱。

科隆也达到12.5%。

而家庭拿到税后工资以后，还需要消费。

德国2021年的标准VAT[^vat]税率为19%，但并不是每一笔家庭支出都适用这个税率，也不是全部劳动收入都会在当年用于消费。

因此，这里没有把19%直接乘以家庭全部消费。

模型根据德国居民消费和微观税负研究，估算不同收入家庭实际承担的增值税以及能源、机动车和其他消费税费。

最终：

| 消费税项目           | Munich   | Cologne  |
| -------------------- | -------- | -------- |
| VAT现值              | €207,069 | €187,439 |
| VAT占劳动价值        | 5.3%     | 5.6%     |
| 其他消费税PV         | €64,709  | €60,642  |
| 其他消费税占劳动价值 | 1.7%     | 1.8%     |

慕尼黑消费税合计约7.0%，科隆约7.4%。

科隆的绝对缴税金额低于慕尼黑，但占生命周期劳动价值的比例反而略高。

这与间接税的一个常见特点有关：收入较低的家庭往往需要把更高比例的可支配收入用于日常消费，因此消费税占劳动价值的比例未必随着收入降低而下降。

现在，把养老金、医保、个人所得税和消费税全部放到一起。

| 财政与社会保险项目      | Munich    | Cologne   |
| ----------------------- | --------- | --------- |
| 养老金净汲取            | 8.0%      | 8.0%      |
| 医疗净汲取              | 6.7%      | 5.5%      |
| 个人所得税              | 14.2%     | 12.5%     |
| VAT                     | 5.3%      | 5.6%      |
| 其他消费税              | 1.7%      | 1.8%      |
| **财政/社会保险净汲取** | **35.8%** | **33.4%** |

*各分项百分比已经四舍五入，合计以模型未舍入金额为准。失业、护理、工伤等社会保险在当前模型中按照缴费与预期福利等值的保守规则处理，净汲取暂计为0，而不是不存在缴费。*

这就是德国LCER最主要的部分。

**慕尼黑35.8%，科隆33.4%。**

而且这个结果已经扣除了养老金和医保福利。

<figure class="fr-figure"><img src="https://kewtgh.github.io/PicSunflowers/img/2026/ai-germany-the-government-took-the-money-01.jpg" alt="ai-germany-the-government-took-the-money-01" /></figure>

它们不是税率简单相加的结果，而是标准家庭在整个生命周期中，经过可识别福利回流之后，仍然承担的净财政和社会保险成本。

我们前面计算法国时，Paris这一项是31.2%，Lyon是25.6%。

德国两座城市都更高。

当然，不同国家的养老金制度、医保资金来源和工资分布并不完全相同，不能只凭这四个数字就断言德国所有群体的实际税负高于法国。

但至少对于当前设定的两类普通双职工家庭，德国的财政和社保净负担确实相当重。

## 六、慕尼黑房价很贵，但它不是上海

现在来看住房。

这次德国最容易让人觉得反常的，可能正是这一部分。

2021年，慕尼黑二手产权公寓的代表性成交价格大约达到每平方米€9,100。

统一按照80平方米计算：

**€728,000。**

科隆模型采用每平方米约€4,620的代表价格：

**€369,600。**

于是：

| 住房项目         | Munich     | Cologne    |
| ---------------- | ---------- | ---------- |
| 80平方米住宅价格 | €728,000   | €369,600   |
| 房价/家庭年工资  | **6.48倍** | **3.86倍** |

慕尼黑的房价几乎是科隆的两倍。

而且6.48倍的房价收入比，对一个普通双职工家庭来说已经相当高。

大家可能会问：既然慕尼黑房价这么高，为什么它的住房制度性汲取却很低？

这就要回到中国篇反复讨论过的一个问题：

**高房价，并不必然意味着等额的制度性汲取。**

上海当初算出来101.8%，其中最重要的不是普通商品房的建筑成本，而是土地财政所形成的制度性成本，以及高房价进一步带来的住房杠杆和长期融资成本。

德国不是这种土地财政结构。

德国也有土地供应限制、城市规划、建筑监管，以及各种会影响住房供给的制度。这些制度确实可能推高住房价格。

例如2021年德国央行就曾估计，德国部分城市住房价格相对于基本面存在约10%至30%的高估。

但是，这类价格高估并不能直接等同于制度性汲取。

房价可能受到土地稀缺、收入增长、人口集聚、低利率、未来价格预期和规划限制等多种因素共同影响。

如果没有足够可靠的反事实研究，能够把正常市场价格与制度限制造成的额外成本区分开来，就不能简单地把房价溢价全部塞进LCER。

因此，德国本轮模型暂时只纳入能够明确识别的房地产交易税：

**Grunderwerbsteuer[^grunderwerbsteuer]。**

2021年：

- 慕尼黑所在的Bavaria（巴伐利亚州）：**3.5%**
- 科隆所在的North Rhine-Westphalia（北莱茵-威斯特法伦州）：**6.5%**

也就是说，慕尼黑的房价几乎是科隆两倍，但买房时适用的房地产交易税率反而更低。

把购房安排在职业第10年，并折现回25岁以后：

| 住房制度成本           | Munich   | Cologne  |
| ---------------------- | -------- | -------- |
| 房地产交易税率         | 3.5%     | 6.5%     |
| 制度性住房成本PV       | €20,902  | €19,708  |
| **占生命周期劳动价值** | **0.5%** | **0.6%** |

**只有0.5%和0.6%。**

这并不是说德国政府不会从房地产中征税。

也不意味着德国住房市场没有制度问题。

年度房地产税Grundsteuer[^grundsteuer]、规划造成的供给约束、建筑监管成本，以及其他尚未可靠量化的收费，目前都没有完整纳入这个中心估值。

但至少可以确定，德国住房体系不能直接套用上海的土地财政模型。

仅仅因为慕尼黑房价昂贵，就认定德国政府通过房地产拿走了同样比例的家庭财富，这个推论缺乏依据。

## 七、德国房贷利率很低，所以融资成本也不高

房价很高，不代表房贷成本一定按相同比例上升。

2021年的德国，正处于长期低利率环境。

德国央行当时的长期固定住房贷款利率已经非常低。模型采用的贷款利率约为：

**1.3%。**

仍然按照前面国家相同的首付和贷款比例：

- 首付30%
- 贷款70%
- 贷款期限30年
- 完全摊还[^amortization]

并假定后续再融资利率维持2021年基准条件，以保持统一静态比较口径。

最后得到：

| 房贷项目               | Munich   | Cologne  |
| ---------------------- | -------- | -------- |
| 房价                   | €728,000 | €369,600 |
| 贷款本金               | €509,600 | €258,720 |
| 贷款利率               | 1.3%     | 1.3%     |
| 房贷利息PV             | €72,332  | €36,722  |
| **占生命周期劳动价值** | **1.9%** | **1.1%** |

慕尼黑家庭为了购买这套72.8万欧元的住宅，需要借款50.96万欧元。

但30年贷款的利息折现到职业起点以后，只有约7.23万欧元。

相当于生命周期劳动价值的1.9%。

科隆则只有1.1%。

这和中国篇的结果差别非常大。

上海的房贷利息一项就达到30.8%，而德国慕尼黑只有1.9%。

当然，这并不意味着2021年德国所有实际购房者都能在未来30年持续享受1.3%的利率。

本模型使用的是2021年静态利率。如果未来再融资利率上升，贷款成本自然也会增加。

但从同一基准年进行比较，德国的住房融资结构确实和上海完全不同。

**慕尼黑的房子很贵，但昂贵的房价没有在模型中进一步转化成同样巨大的融资利息。**

这也解释了为什么慕尼黑房价收入比已经达到6.48倍，住房融资却没有成为德国LCER的主要来源。

## 八、德国还有一项很特别的强制收费：Rundfunkbeitrag

德国还有一个比较有意思的制度：

**Rundfunkbeitrag[^rundfunkbeitrag]，公共广播电视费。**

只要符合缴费条件，普通住宅原则上就需要按户缴纳。即使家庭实际上很少观看公共电视节目，也不会自然地免除缴费义务。

2021年1月至7月，每户每月缴纳€17.50。

从8月开始，提高到€18.36。

因此，全年标准缴费约为：

**€214.30。**

这笔钱看起来不多。但是如果一个家庭从年轻一直缴纳到退休以后，按照夫妻中预期寿命较长者的寿命计算，累计下来的金额也不能忽视。

折现以后，大约为：**€7,689。**

对应：

- Munich：**0.20%**
- Cologne：**0.23%**

我把它放进Extended LCER[^extended-lcer]，没有纳入Core LCER。

这里的原因并不复杂。

公共广播当然提供服务，也可能产生公共价值，但这种按住宅强制缴纳的费用，并不对应一项可以明确计入家庭资产或按个人领取的现金福利。

所以它作为德国特有的强制制度支出，单独列示更合适。

但它在整个德国LCER中，实际上只占很小一部分。

德国还有其他项目没有完整计入。

例如教育。

德国普通家庭的教育支出占消费比例约0.7%，低于本系列统一采用的日本1.5%教育竞争基准[^education-baseline]，因此目前没有可识别的超额教育竞争成本。

这不是说德国教育没有费用，也不是说公立教育没有公共财政成本。

只是按照我们此前确定的模型，德国没有出现需要额外计入的家庭超额教育竞争支出。

失业保险、护理保险、工伤保险等项目，由于缺乏足够可靠的普通家庭生命周期福利概率数据，暂时将缴费和福利视为等值，净汲取记为0。

规划造成的住房稀缺溢价、年度房地产税以及部分能源和公共事业制度成本，也暂时没有进入中心估值。

这些未计入项目并不一定很小。

只是目前还没有足够可靠的数据将它们转化为普通家庭的生命周期净成本，同时避免和已有税费重复计算。

## 九、把德国的账放到一起

现在，把德国所有能够明确计入的项目放在一起。

### Munich

财政和社会保险净汲取：**35.8%。**

住房制度成本：**0.5%。**

房贷利息：**1.9%。**

得到：**Core LCER：38.2%。**

再加入公共广播电视费等已经识别的国家特有强制支出：**0.2%。**

最后得到：

> **Total LCER：38.4%。**

对应家庭生命周期劳动价值现值约€391.7万，已计入的生命周期制度性净成本约：

**€150.2万。**

### Cologne

财政和社会保险净汲取：**33.4%。**

住房制度成本：**0.6%。**

房贷利息：**1.1%。**

得到：**Core LCER：35.1%。**

再加入国家特有强制支出：**0.2%。**

最后得到：

> **Total LCER：35.3%。**

对应家庭生命周期劳动价值现值约€333.7万，已计入的制度性净成本约：

**€117.8万。**

完整结果如下：

| 项目                      | Munich       | Cologne      |
| ------------------------- | ------------ | ------------ |
| 财政/社会保险净汲取       | **35.8%**    | **33.4%**    |
| 住房制度成本              | 0.5%         | 0.6%         |
| 房贷利息                  | 1.9%         | 1.1%         |
| 超额教育竞争              | 0.0%         | 0.0%         |
| 住房供给限制溢价          | Not Included[^not-included] | Not Included |
| 其他尚未量化的制度成本    | Not Included | Not Included |
| **Core LCER**             | **38.2%**    | **35.1%**    |
| 公共广播电视费等扩展项    | 0.2%         | 0.2%         |
| **Total / Extended LCER** | **38.4%**    | **35.3%**    |

两座城市之间相差3.1个百分点。

<figure class="fr-figure"><img src="https://kewtgh.github.io/PicSunflowers/img/2026/ai-germany-the-government-took-the-money-02.jpg" alt="ai-germany-the-government-took-the-money-02" /></figure>

有意思的是，德国城市之间的差距主要不来自住房制度税费。

慕尼黑所得税负担更高，医保缴费高于科隆，但医疗福利并没有按收入同比增加。这些差异推高了慕尼黑的净汲取率。

住房融资也增加了一部分差距，不过只贡献约0.8个百分点。

所以我们看到的并不是一个类似上海与南京的住房成本差异模型。

德国的主要制度成本，更直接地和劳动收入联系在一起。

*德国采用Extended LCER；其他国家采用此前文章已发布的最终结果。各国部分尚未货币化的制度项目并不完全相同，因此这些数字应视为统一模型下的中心估值，而不是精确到小数点后一位的国际福利排名。*

现在有些差异已经很明显。

例如Toronto是34.1%，Paris是34.0%，两个数字几乎相同。

但在加拿大，Toronto的财政和社会保障净汲取只有19.6%，其余相当大的一部分来自住房制度和融资。

Paris则有31.2%来自财政与社会保障净汲取。

到了德国，Munich更进一步：

**35.8%的财政和社会保险净汲取，已经超过Toronto和Paris的整体LCER。**

而德国慕尼黑的住房制度成本和房贷利息合计只有2.4%。

科隆也很特别。

它的35.3%，不仅高于Lyon的27.8%，甚至已经超过Paris的34.0%。

也就是说，德国并不是只有最昂贵的慕尼黑，才会出现较高的生命周期综合汲取率。

对于科隆这样的大型代表城市，一个普通双职工家庭即使不承担慕尼黑的房价，仍然有超过三分之一的生命周期劳动价值进入当前模型识别的制度性净成本。

不过，这些数据也不能直接解释成“德国福利最差”。

LCER目前能够比较的是按照统一规则识别、估算和扣除的制度性现金流与可归属福利。它并没有完整衡量治安、基础教育、公共基础设施以及其他公共服务给居民带来的全部价值。

所以我们可以判断家庭承担的可识别净成本高低，却不能仅凭LCER判断一个国家的整体生活质量或公共支出效率。

而且德国住房规划限制、年度房地产税等项目没有完整计入，未来补充研究以后，数据仍然可能变化。

德国这次的结果，至少已经把一个问题说明白了。

## 十一、德国的钱，是在劳动过程中被拿走的

前面写法国的时候，我曾经提到：

法国政府很会拔鹅毛，因为大量的钱在进入劳动者账户以前，就已经通过税收和社会保障体系被收走了。

现在来看德国，这种机制同样非常明显。

德国为普通劳动家庭提供了完善的养老金、医疗和其他社会保障，但是它也需要劳动者以及雇主持续缴纳大量费用。

这些费用有一部分会在未来以养老金和医疗福利的形式重新回到家庭，另一部分则被用于社会保障体系内部的再分配，以及其他公共支出。

从一个普通家庭自己的生命周期账本看，扣除了目前能够识别的福利以后，德国仍然留下了相当高的净制度成本。

与上海相比，德国政府并不需要通过高额土地出让收入和巨大的房贷利息，才能让家庭承担大量制度成本。

**德国的汲取主要发生在劳动价值形成、工资分配和日常消费的过程中。**

慕尼黑38.4%，科隆35.3%。

这两个数字说明了一件事：

**一个国家即使拥有完善的公共福利制度，也不意味着普通家庭创造的劳动价值会有更高比例最终留在自己手中。**

而福利究竟能不能抵消这种成本，不能靠“高福利国家”这个标签回答。

只能把交出去的钱和最终回到家庭的福利，一笔一笔重新算清楚。

[^lcer]: **LCER（Lifecycle Comprehensive Extraction Rate，生命周期综合汲取率）**：本系列使用的测算指标，等于“可识别的制度性生命周期净成本现值 ÷ 家庭生命周期劳动价值现值”。它不仅考虑税收和强制社会保险，还考虑符合模型口径的住房制度、融资及其他制度性成本；同时扣除能够归属于家庭的养老金和医疗福利。LCER不是通常意义的税率，也不能单独衡量公共服务质量。

[^tax-wedge]: **Tax Wedge（劳动税楔）**：雇主全部劳动成本与劳动者扣除个人所得税、雇员社会保险等项目后的净收入之间的差额，占雇主劳动成本的比例。本文引用的德国48.1%和法国47.0%是OECD针对**单身、无子女、领取平均工资劳动者**的2021年统计值，与本文双职工一孩家庭的终身净成本口径不同。参见[OECD《Taxing Wages 2022》](https://www.oecd.org/en/publications/taxing-wages-2022_f7f1e68a-en.html)。

[^discount-rate]: **实际贴现率（Real Discount Rate）**：将未来的工资、缴费、福利和其他成本转换为同一基准时点价值时使用、已剔除通胀影响的折现率。本系列统一设定为2%，并假定长期实际工资增长率为0%；这两项均属于模型假设，而不是对德国未来经济走势的预测。

[^city-type]: **Leading City / Representative City（头部城市／代表城市）**：本系列每个国家选择两座城市进行比较。头部城市一般具有更高的工资、生产率或住房成本；代表城市则用于观察较普通的大型城市家庭。两座城市的比较不能代表一国所有地区、所有收入群体。

[^median-wage]: **社会保险就业工资中位数**：依据德国社会保险体系登记的就业者工资数据得到的统计指标；中位数表示样本一半高于该值、一半低于该值。本文使用全职、受社会保险覆盖的就业者口径，不能直接代表兼职者、自雇者、公务员或全部居民。工资数据参见[2021年德国地区工资中位数汇编](https://biaj.de/images/2022-07-25_entgelt-median-laender-und-kreisvergleich-wohnort-arbeitsort-2021.pdf)。

[^pv]: **PV（Present Value，现值）**：把不同年份产生的收入或支出折算到同一时点后的数值。本文统一折现至25岁开始工作的时点，所以“生命周期劳动价值PV”并不是家庭一生未折现工资的简单相加。

[^grv]: **Gesetzliche Rentenversicherung（德国法定养老保险）**：德国公共退休收入保障的重要组成部分，主要以在职缴费支持当前养老金支付，个人退休待遇取决于缴费记录、养老金积分和法定计算规则。2021年一般缴费率合计为18.6%，雇主与雇员通常平分。参见[Deutsche Rentenversicherung](https://www.deutsche-rentenversicherung.de/)。

[^gkv]: **Gesetzliche Krankenversicherung（GKV，德国法定医疗保险）**：德国主要的法定疾病保险制度，采取按工资缴费、按医疗需求享受待遇的社会保险方式。2021年一般缴费率14.6%，另有疾病基金附加缴费，所引1.3%是当年的平均附加费率；个人缴费受到法定收入上限约束。

[^entgeltpunkte]: **Entgeltpunkte（养老金积分）**：德国法定养老金计算个人待遇的基础指标之一。一个缴费年度的相关收入与当年平均收入比较，形成相应积分；退休金取决于累计积分及其他法定因素。它不同于把个人缴费原样存入专属投资账户。

[^replacement-rate]: **Gross Replacement Rate（养老金毛替代率）**：养老金毛额相对于退休前工资的比例，未扣所得税等项目。正文的41.5%来自OECD养老金模型；38.7%为适配本系列25岁开始、42年工龄而作的近似年限调整，不是德国对所有退休者规定的统一养老金比例。参见[OECD《Pensions at a Glance 2021》](https://www.oecd.org/en/publications/pensions-at-a-glance-2021_ca401ebd-en.html)。

[^conditional-life]: **条件剩余寿命（Conditional Remaining Life Expectancy）**：以一个人已经活到某年龄为前提，估算他此后还会生存多少年。计算67岁开始领取的养老金，应参考活到67岁的人的剩余预期寿命，而不能用“出生时预期寿命－67”代替。

[^einkommensteuer]: **Einkommensteuer（德国个人所得税）**：对个人应税收入征收的累进税；边际税率只适用于相应收入区间，不等于全部收入的平均实际税率。家庭申报及可扣除的社会保险、儿童税收待遇等，都会影响最终税负。参见[德国联邦财政部2021年所得税法§32a](https://amtliche-handbuecher.bundesfinanzministerium.de/esth/2021/A-Einkommensteuergesetz/IV-Tarif/Paragraf-32a/inhalt.html)。

[^kindergeld]: **Kindergeld（儿童津贴）**：德国向符合条件的家庭支付的儿童现金福利。2021年前两个孩子各为每月€219；德国还存在Kinderfreibetrag（儿童免税额），税务系统会按适用规则比较，不能将两种优惠不加区分地重复计算。

[^vat]: **VAT（Value Added Tax，增值税；德国称Umsatzsteuer或Mehrwertsteuer）**：德国2021年一般税率为19%，部分商品和服务适用7%优惠税率或免税规定。家庭实际承担的VAT取决于消费金额及结构，因此19%不能直接乘以家庭全部工资。

[^grunderwerbsteuer]: **Grunderwerbsteuer（不动产取得税）**：德国房地产交易发生应税产权转移时征收的税，税率由各联邦州确定。2021年巴伐利亚州为3.5%，北莱茵-威斯特法伦州为6.5%。它是购房环节的交易税，与每年征收的Grundsteuer不同。

[^grundsteuer]: **Grundsteuer（年度房地产税）**：德国地方政府针对土地和房地产征收的经常性税收，区别于买房时缴纳的Grunderwerbsteuer。实际税额受物业计税基础、税额系数和地方税率影响；本文未取得可按统一模型可靠估值的两城样本物业数据，因此没有直接计入。

[^amortization]: **完全摊还（Fully Amortizing Mortgage）**：贷款期内通过定期还款逐步偿还全部本金，并同时支付剩余本金对应的利息，到期时本金余额为零。本文LCER只计融资利息，不把偿还本金当作制度性汲取，因为本金偿还同时减少家庭负债。

[^rundfunkbeitrag]: **Rundfunkbeitrag（德国公共广播缴费）**：通常按住宅而非每台设备收取、用于支持公共广播服务的法定费用；存在法定豁免或减缴情形，是否实际收看节目一般不决定缴费义务。2021年1月至7月每月€17.50，8月起€18.36。参见[德国公共广播缴费官方说明](https://www.rundfunkbeitrag.de/presse-und-aktuelles/hinweise/beitragsanpassung-2021/haeufige-fragen-zur-beitragsanpassung)。

[^extended-lcer]: **Core LCER / Extended LCER（核心／扩展汲取率）**：Core为跨国统一框架中的核心可量化净制度成本；Extended在Core基础上加入明确识别、能够货币化的国家特有强制支出。德国的Rundfunkbeitrag按本次模型纳入Extended，而非Core。不同国家是否已计入扩展项目，应在比较时区分。

[^education-baseline]: **超额教育竞争成本基准**：本系列采用1.5%的家庭消费教育支出比例作为统一比较阈值，并以日本基准作为参考。仅超出这一阈值、且满足模型条件的部分才纳入“超额教育竞争”。它属于本系列的模型设定，不代表德国不存在教育支出或教育不平等。

[^not-included]: **Not Included（未纳入估值）**：表示已经识别出潜在制度性成本，但缺乏可靠、适用且能够避免重复计算的家庭级金额，因此没有加入本次LCER合计。它与经过测算确认的0%不同，也不能据此断言相关成本不存在。
