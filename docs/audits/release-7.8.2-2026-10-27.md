# FaceReader 7.8.2：恢复日本篇中文版的注释

## 原因与证据

2026-10-27 只读检查[日本篇中文版](https://facereader.witbacon.com/%E7%A4%BE%E4%BC%9A%E6%9D%82%E8%AE%BA/Society-lcer-japan/)：HTTP 200，正文残留 16 个 `[^口径]` 等原始脚注标记，0 个脚注链接、0 个注释列表。本地生产产物可复现；本地产物中的英文版正常。

项目锁定的 kramdown 2.5.2 的脚注名采用 `\w[\w-]*`，当前 Ruby 实现中的 `\w` 不匹配汉字。中文标记未成为脚注引用，文末定义也未生成注释内容，因此“注释”标题下为空。问题发生在 Markdown 转换阶段，悬浮预览脚本没有收到可供增强的脚注节点。参见[官方语法](https://kramdown.gettalong.org/syntax.html#footnotes)和安装的解析器 `parser/kramdown/footnote.rb`、`extensions.rb`。

此前 HTML 检查覆盖链接、图片和结构，浏览器脚注样本未包括新日本篇，遗漏了尚未转换的 Markdown 标记。

## 修改计划

1. 将中文文章的 16 组引用与定义标识改成与英文版相同的 ASCII 名称，保留正文、注释内容、来源和现场已有空行调整；清理一处被修改行原有的行末空格。
2. 在全站 HTML 审计中拦截文章正文残留的脚注标记，跳过代码示例；新增包含不兼容标识、缺失定义和代码示例的回归测试，检查两篇日本文章的全部 16 条脚注及返回链接。
3. 将中英文日本篇加入桌面及移动端浏览器脚注回归，验证编号、正文跳转、注释列表、弹出预览、关闭和焦点恢复。
4. 更新至 7.8.2，完成生产构建与验证，保存记录并本地提交。已有用户空行修改不纳入本次提交。
