# FaceReader 7.7.1：阅读入口与页脚修订

日期：2026-10-24。此记录保存 7.7.0 发布后的补充审计、修改计划和验收结果；之前的审计记录保留原貌。按用户反馈，本文替代之前关于独立查找文章和页脚隐私设置的方案。

## 补充审计

以博客的主要任务「阅读、发现内容、收藏以后阅读」重新检查 UI：

| 问题 | 原因与影响 | 处理 |
| --- | --- | --- |
| 页脚重复导航、设置和冗长版权说明挤在一起 | 把低频设置与关注、订阅混排，破坏页脚层次 | 重排为关注及双语 Feed、简短版权两层 |
| 新增的查找文章与已有全站搜索重复 | 同一任务出现两个入口和两套搜索逻辑 | 删除独立搜索页、目录请求及相关交互，保留全站搜索和失败重试 |
| 稍后阅读页比文章归档明显窄 | 独立布局和独立卡片样式偏离现有归档体系 | 直接复用 `/posts/` 容器、双栏、侧栏及卡片 |
| 文章收藏操作与版本切换分散 | 阅读操作不成组，按钮层次和尺寸不统一 | 顶部左侧放收藏/列表操作，右侧保留文章版本，统一按钮样式 |
| 页脚隐私设置超出用户期望 | 为个人博客添加了额外设置流程 | 移除设置面板及偏好存储逻辑；统计按站点配置加载，保留 DNT/GPC 支持 |
| 归档卡片仍使用旧阅读时长公式 | 与文章正文的统一计算结果不一致 | 卡片读取构建时统一的 `reading_minutes` |
| 窄屏下返回顶部按钮盖住版权文字 | 固定工具栏没有避让页脚 | 页脚进入视口时将工具栏上移，保持订阅链接及版权可读、可点击 |

主站与分站域名按既有配置保留。X、Facebook、LinkedIn 的主页链接是用户刻意保留的匿名入口。

## 修改计划

1. 合并关注和订阅，提供中文 Feed、英文 Feed；移除页脚查找文章、稍后阅读和隐私设置。
2. 提取共享归档导航，以稍后阅读替换查找文章；404 使用既有全站搜索。
3. 用同一布局和服务端卡片模板渲染收藏列表，继续使用 `facereader.readingList.v1`，保留收藏顺序、跨标签同步、移除、失效清理和存储错误提示。
4. 重排文章工具栏，验证中英文及窄屏下的同排、对齐和触控尺寸。
5. 删除独立本地搜索、目录接口、设置脚本和无效样式，更新说明与回归检查。
6. 使用既定稳定/LTS 依赖进行生产构建、静态检查、完整浏览器回归和截图复核；更新至 7.7.1 并本地提交。
