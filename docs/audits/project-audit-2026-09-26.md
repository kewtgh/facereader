# FaceReader 项目与应用审计（2026-09-26）

## 范围与边界

基线：7.1.8。审查 Jekyll layouts/includes、文章/目录、Posts、Categories、Tags、导航/i18n、搜索、LEADERS 查询/比较/报告、评分纯函数、数据校验和构建门禁。现有项目是静态 Jekyll 网站，没有独立 company/report 后端或真实个人履历生成服务；LEADERS 是结构化企业数据的客户端展示。保留此前 2026-07-27 和 2026-09-25 审计，不改写旧记录。

本轮不调整任何企业的事实、分数、证据等级、历史文章或 URL，不引入服务端、支付、账户、第三方库。不把企业评分宣传为个人 Leader Profile。以下是代码审计，不是对外部来源真实性或网站全部内容的认证。

## 发现（修改前）

|编号|级别|证据与影响|整改|
|---|---|---|---|
|A01|P1|`category-map.js` 缓存被拒绝的 Promise，catch 隐藏详情；后续分类点击永远复用失败。异步完成时不检查 hash，离开分类后仍可能显示旧内容并抢滚动。|请求状态、过期请求保护、可重试错误、可访问状态；数据路径由 Liquid 输出。|
|A02|P1|`site-ui.js/syncTocLabels` 把全页所有目录链接按一个 index 对应可见语言 headings；存在桌面/移动/克隆目录时后面的链接会被误隐藏。|按每份目录独立匹配。|
|A03|P2|`article-toc.js` 仅初始化桌面目录、只建一次 heading 关联、写死 160px，切换 UI 语言/目录 href 后仍观察旧节点。|重建关联、共用桌面/移动 active 状态、根据 header offset 定位，尊重 reduced motion。|
|A04|P2|UI 语言切换修改 html.lang，但中文文章内容并不会自动翻译；正文未单独标记语言。|文章正文保留实际 locale，翻译块仍自行标记 lang。|
|A05|P1|LEADERS runtime 仅检查数组非空；model/data 坏项可在点击时抛异常。CLI 对非数组 sources/aliases 继续迭代，可能 TypeError 而非清晰诊断。Darwin bands、未来日期等未充分校验。|共用严格数据契约用于浏览器/CLI/测试；保留缺资料警告，不伪造资料。|
|A06|P1|`scoreKeys` 默默丢弃空项、允许重复维度；`scoreBandLabel` 对 >10 值可给最高评级；canonical 重名匹配可能继续落到 alias/fuzzy；`stage=toString` 被继承属性误认成模式。|无效输入显式拒绝；同名冲突只返回候选；模式必须是自有属性。|
|A07|P2|LEADERS load failure 只写结果文案，总表仍停留 loading；无 timeout/retry，切换语言可能留下半初始化 UI。|有界请求、统一失败状态与重试、成功前不绑定业务事件。|
|A08|P2|对比栏默认塞满三个高分企业，加入企业会静默替换末位；切换语言按输入草稿重新执行查询，导致当前报告跳到未提交的企业。|对比从空开始、满位明确提示，不覆盖；语言切换依据 URL 中已提交查询恢复。|
|A09|P2|`addReturnParam` 字符串拼接在 hash 后加 query，含锚点链接的返回标识无效。|用 URL API 保留 query/hash。|
|A10|P2|目前测试主要检查算术和生成 HTML，不覆盖异步分类失败、语言切换、输入状态和运行时报告。|增加 DOM 状态回归和可执行 Chromium smoke suite；挂入常规检查的无需浏览器测试。|
|A11|P1|Chromium 实测 LEADERS 在 1024px 视窗产生 1063px 页面宽度；筛选栏固定 minmax 列宽和不可换行的 flex 将操作区挤出页面。|允许工具栏换行、列可收缩，保持表格只在自身容器内滚动。|
|A12|P1|Pages workflow 仅检查构建文件/CSS 大小，没有执行现有 site:check；数据、评分和 HTML 测试失败仍可发布。|完整检查阻断 artifact 上传，workflow lint 防止门禁被遗漏。|
|A13|P2|搜索依赖加载失败仅 console.error，访客面对空搜索区域；script 请求没有超时。|15 秒超时、可见失败反馈/重试/文章归档退路，不调用外部写入。|

## 纳入本轮的新能力

1. **评分可解释性**：当前企业显示七项分值、所选权重和贡献值，并列三种阶段结果；说明这是模型情景，不是新事实、置信区间或概率。
2. **分类快速查找**：全部分类支持本地名称搜索、匹配计数、无结果提示，保留原分类锚点与图文列表。

用户补充边界：这是个人博客，不是专业企业分析网站。明确取消新增下载/导出研究快照，不扩展商业分析平台功能。已有打印功能不在本轮删除范围。

## 不可自动解决的资料治理问题

前次审计的缺复核日期、缺公开来源、共享别名和评分偏差仍须编辑核验。不能把代码修改当成企业事实复核。真正的个人档案、历史评分库、逐维度来源链需要底稿/数据再建设；本轮不伪造填充，也不承诺尚不存在的商业报告交付。此类事项作为已知限制而非本轮未接线功能。
