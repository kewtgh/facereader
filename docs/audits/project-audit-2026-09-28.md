# FaceReader 项目复审（2026-09-28）

范围：当前 7.1.9 源码、`_site` 构建产物、Jekyll 配置、系列/分类页面、发布检查和现有浏览器回归。基线提交 `05e863d`，审计开始时工作树干净。此前审计见 [2026-09-26 记录](project-audit-2026-09-26.md)。本次是个人博客的可靠性和阅读体验复审，不把 LEADERS 页面发展为专业分析产品，不增加下载/导出功能，也不擅自改写评分或文章事实。

## 确认的问题

|ID|级别|证据与影响|整改|
|---|---|---|---|
|A01|高|`research/leaders/` 是评分证据与复核笔记，但 `_config.yml` 未排除；现有 `_site/research/leaders/` 有 34 个文件（17 个原始 Markdown、17 个渲染页面），`_site/sitemap.xml` 包含对应 URL。内部编写材料意外公开且可被索引。|从 Jekyll 发布范围排除整个 `research` 目录；构建审计检查输出目录和 sitemap。源文件仍供本地校验使用。|
|A02|中|`docs/_pages/category-archive.md` 以 `sitemap: false` 和 `robots: noindex` 发布，生成的 `/categories/` 含 noindex，sitemap 缺席。该页现为公开阅读地图、站内主要导航入口。|允许索引并纳入 sitemap；保留 `/tags/` 的独立策略。|
|A03|中|`_layouts/series.html` 对按 Front Matter `series` 聚合的系列无条件生成英文列表；未来新增只有中文的系列时，英文 UI 会切到空列表。列表计数也固定为中文篇数，并可能计入 `hidden` 项。|根据实际英文文章决定是否双语切换；按可见文章分别计数；无译文时保留原文列表。|

|A05|低|390px 文章页截图中页眉品牌被截成 `FaceReade…`；完整中英品牌名称在窄屏上无法容纳。|窄屏显示简短 `FaceReader`，保留完整名称作为链接可访问名称；桌面维持现状。|

## 检查后不改的事项

- `/tags/` 的 noindex 用于避免标签聚合与文章页竞争；本轮没有证据需要改为索引。
- 现有静态分页、文章 permalink、canonical、正文内容与评分模型保留。`research_file` 字段是源数据与本地验证器的证据路径，不是公共下载入口。
- 当前系列数据中 LCER 有中文和英文各 3 篇，因此 A03 是可证实的扩展缺陷而非已发生的 LCER 空白事故。

## 后续人工核实

- 部署后核对线上 `/research/` 是否已从新构建移除；已经被搜索引擎发现的旧 URL 可能需要通过站长工具请求重新抓取/移除，构建修复本身不能清除外部缓存。
- 文稿准确性、图片授权与评分依据仍需作者定期复审；自动化只能检查结构与数据契约，不能替代编辑判断。
